# 🔄 BetterConverter — File Conversion Tools

A fast, modern, and privacy-friendly file conversion web app built with
pure HTML, CSS, and JavaScript. All conversions happen directly in your
browser — your files never leave your device.

## ✨ Features
- 8 powerful conversion tools in one place
- Drag & drop file upload
- Live file preview before converting
- Progress bar animation
- Toast notifications
- 100% browser-based — no server, no uploads
- Fully responsive on mobile & desktop
- Dark modern UI

## 🛠️ Tools Available
- 📄 PDF to Word (Text Extraction)
- 📝 Word / Text to PDF
- 🖼️ Image to PDF (JPG, PNG, WEBP)
- 🔍 PDF to Image (PNG export)
- 📊 Excel / CSV to PDF
- 🔗 Merge PDFs
- 🗜️ Compress PDF
- ✏️ Text to PDF

## 💻 Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- jsPDF
- PDF.js
- PDF-lib
- PapaParse

## 🚀 How to Run
1. Clone the repository
2. Open folder in VS Code
3. Right-click index.html → Open with Live Server
   OR run: python -m http.server 8000
4. Open http://127.0.0.1:8000 in Chrome
